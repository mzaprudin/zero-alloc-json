Компоненты на C# / .NET 10 для потоковой обработки JSON с низкими задержками. Оптимизированный парсинг сокращает время обработки, а переиспользование объектов и буферов снижает нагрузку на сборщик мусора. Это помогает сохранять предсказуемые задержки и стабильную работу системы при непрерывном потоке данных.

**0 B/op в прогретых сценариях с переиспользованием.** Метаданные, ёмкость коллекций и интернированные символы подготовлены до измерения; инициализация, рост и новые строки выделяют память.

## Переиспользование на практике

Объект результата создаётся один раз. Здесь `intern` — сохранённый делегат интернирования, а `writer` — переиспользуемый `Utf8JsonWriter`:

```csharp
var trade = new Trade();
JsonPopulator.Populate(firstUpdate, trade, intern);
JsonPopulator.Populate(nextUpdate, trade, intern); // Обновляется тот же объект.
JsonPushulator.Push(trade, writer);
writer.Flush();
```

[Полный пример разбора и записи](samples/ZeroAlloc.Json.Demo/Program.cs) · [Владение памятью и поведение парсера](docs/architecture.ru.md)

### Инженерные решения

- **Переиспользование результата.** `JsonPopulator` обновляет готовые классы, структуры и элементы `FastList<T>`. При частичном обновлении отсутствующие поля сохраняют прежние значения.
- **Однократная подготовка.** Поиск полей и скомпилированная запись кэшируются для каждого типа. Вызывающий код переиспользует `Utf8JsonWriter` и выходной буфер.
- **Повторное использование строк.** Интернирование сохраняет уже встреченные символы; фиксированные строки дают ещё один способ обходиться без managed string.
- **Маршрутизация по входным байтам.** Маршрутизатор компактных сообщений находит символ в UTF-8 и определяет его идентификатор без построения дерева объектов.

## Сборка и запуск примера

Требуется .NET 10 SDK:

```sh
dotnet restore ZeroAlloc.Json.sln --locked-mode
dotnet build ZeroAlloc.Json.sln -c Release --no-restore
dotnet test tests/ZeroAlloc.Json.Tests -c Release --no-build
dotnet run -c Release --no-build --project samples/ZeroAlloc.Json.Demo
```

Пример сверяет разобранные поля и записанные байты с System.Text.Json. Тесты проверяют переиспользование результатов, escape-последовательности, сегментированный вход, числа в строках, GUID и запись JSON. CI на Linux и Windows запускает тесты, пример и каждый benchmark-сценарий.
