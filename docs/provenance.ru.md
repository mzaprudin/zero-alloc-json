# Происхождение и границы переноса

[English](provenance.md) · [Русский](provenance.ru.md)

[Upstream revision 02f7aef](https://github.com/mzaprudin/zero-alloc-json-ws/tree/02f7aefda0933e9a719616ec72bf6f11fc5dd9a8)

Исходный репозиторий служит архивом истории и измерений. Новая ветка main начинается с чистой истории. Лицензионный режим прежний: разрешение по открытой лицензии не предоставлено; NOTICE сохранён побайтно. Лицензии внешних пакетов относятся к их владельцам.

Полная опись исходной ревизии с SHA-256: [upstream-inventory.json](upstream-inventory.json). Соответствие старых и новых путей с хешами до и после: [split-provenance.json](split-provenance.json). Исходное происхождение из GapSonar: [source-provenance.json](upstream/source-provenance.json), [extraction.md](upstream/extraction.md).

Публичные пространства имён и основные API сохранены. Единственное согласованное изменение видимости — internal PoolRental<T> в каждой сборке. Тестовые .cs-файлы перенесены без изменений. JSON routers перенесены из benchmark-файла в библиотеку без изменения тел методов. Изменены упаковка, импорты, friend assemblies и пути инструментов; алгоритмы и фиксированный TCP-буфер сохранены.

Архивные документы в upstream/ и старые сетевые отчёты описывают прежние пути и сборку. Их исходные ссылки можно открыть в зафиксированной исходной ревизии. Свежие замеры имеют собственные source/binary manifests и не заменяют идентичность архивных сборок.

Тестовая сборка сохраняет имя GapSonar.TransportLab.Tests: поиск runtimeconfig/deps в проверке отдельных процессов работает без изменения исходников тестов. Проект и пути тестов принадлежат новому репозиторию.
