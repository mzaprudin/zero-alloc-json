# Архитектура и владение памятью

[English](architecture.md) · [Русский](architecture.ru.md)

`JsonPopulator<T>` кэширует метаданные отражения, поиск имён по UTF-8 и скомпилированные setter-делегаты для каждого закрытого типа. Вход — span или последовательность UTF-8; результат записывается в объект вызывающего кода, структуру по ссылке или переиспользуемый FastList. `[JsonPosition]` поддерживает позиционные массивы. Фиксированные строки позволяют обходиться без managed string; интернирование переиспользует уже встреченные строки.

Инициализация компилирует выражения и выделяет память под метаданные. Для 0 B/op нужны прогретые метаданные, достаточная ёмкость коллекций, повторное использование результата и уже известные интернеру значения. Отсутствующие поля сохраняют прежнее значение. Рост коллекции и новые символы выделяют память. Глобальный интернер для совместимости удерживает символы до конца процесса; отдельный интернер сессии даёт явный срок жизни.

Чтение чисел в строках сохраняет прежнее допускающее поведение: в некоторых случаях принимается числовой префикс или возвращается ноль при ошибке преобразования. Неподдерживаемые поля могут пропускаться. Каждый тип нужно проверять на представительных фикстурах. API не повторяет все проверки и converter-возможности JsonSerializer.

`JsonPushulator` компилирует запись и принимает готовый Utf8JsonWriter. Вызывающий код отвечает за ёмкость, сброс буфера и writer, flush, освобождение и синхронизацию. Нельзя одновременно менять один результат разбора или сбрасывать writer, пока его использует другая операция.

`RouterBenchmark.CustomMessageRouter`, `JsonMessageRouter`, `RegexMessageRouter`, `SymbolLookup` и `IMessageRouter<T>` теперь находятся в библиотеке с прежними пространствами имён. Быстрый router ищет компактный ASCII-маркер `"symbol":"`; для escape-последовательностей и произвольного форматирования нужен полноценный parser. Исходные custom/regex routers копируют многосегментный вход в массив. Бенчмарк использует один сегмент, компактные сообщения и alternate lookup FrozenDictionary.

PoolRental<T> сделан internal. Его отдельная внутренняя копия находится в транспортной сборке: обе библиотеки подключаются без конфликта публичных типов.
